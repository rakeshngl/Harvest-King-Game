Future Development Roadmap

Every possibility grounded in the current game: a 40-tile farming cycle, in-memory rooms, local vs computer, English/Hindi/Tamil chrome, and a Vite + Node split.

Ops Multiplayer Accounts AI Rules Content UX Balance Tech Distribution Sequence

Now — ops after Vercel + Coolify

Keep online rooms alive across deploys and reconnects. Highest leverage after the split host.

  • Room persistence (Redis or SQLite) so Coolify restarts do not wipe games
  • Reconnect by room code + seat token beyond sessionStorage (localStorage, or a join-again flow)
  • Host kick / transfer host if seat 0 disconnects
  • Spectator mode
  • Private rooms + optional password
  • Public lobby list (open rooms waiting for players)
  • Turn timer / auto-skip AFK (90s, TURN_MS) — done
  • Server-side CPU seats (host adds computer farmers in the lobby) — done
  • Graceful drain: this instance is restarting, finish turn (DRAIN_MS) — done
  • Multiple replicas only if rooms are sticky or use a shared store (today: 1 replica only) — deferred, 1 replica
  • Structured logs, error tracking, deeper /api/health checks — done
  • Add a LICENSE — MIT, done

Multiplayer transport

  • WebSockets (or SSE) instead of 20-second long-poll
  • Action replay / late-join mid-game
  • Fast-forward missed dice + landing pop-ups
  • Keep the engine authoritative; clients must not invent moves
  • Rate-limit create/join to stop room spam

Accounts and meta

  • Optional login (Google / email magic link)
  • Named farmer profiles, avatar and coin color unlocks
  • Match history, personal stats (harvests, insolvencies, king wins)
  • Leaderboards: fastest king, highest net worth, season win rate
  • Friends / recent players / rematch
  • Daily challenge seed (same board RNG for everyone)

Vs computer / AI

  • Online mixed tables: 1 human + 1 to 3 CPUs
  • More personas (co-op farmer, organic, exporter, contract farmer)
  • Difficulty that also changes yield/price luck, not only miss chance
  • AI explain panel: leased Barmer because cash buffer
  • Puzzle mode: win in 3 seasons from this save
  • Replay a recorded match vs the same AI seed

Core rules you could add

  • Player trading: land, standing crop, cash, debt
  • Auctions when someone declines to buy
  • Player-chosen mortgage / fire-sale (mortgage is automatic today)
  • Crop contracts (forward sale at a fixed price)
  • MSP vs open mandi vs export as a real choice, not only FCI landing
  • Crop rotation bonus / monoculture fertility penalty
  • Intercropping on large tiles
  • Labour market: extra labour actions cost cash in peak season
  • Farmer producer org / cooperative tile (pool harvest, share bonus)
  • Climate event deck: El Nino year, heatwave, unseasonal rain as a season modifier
  • Policy cards: loan waiver, fertilizer subsidy, export ban with real board effects
  • Livestock / dairy as a side loop on a few tiles
  • Water table: over-irrigation lowers future yield on canal/borewell belts
  • Soil carbon / organic cert as a slow investment (card already exists; make it a track)
  • 5 to 6 players (needs more coins, more belts, or a bigger board)
  • Shorter / longer match presets (12 / 18 / 24 seasons, different WIN_NET)
  • Sandbox / tutor match with forced good monsoon

Content

  • More belts or a second map (South-only, Northeast, one-state district map)

  • Card expansions (more Farmer / Market cards) without engine rewrites
  • Seasonal events tied to festivals already in market cards

Suggested sequence

If building in order, this is the highest-leverage path.

  1. Persist rooms + reconnect (or every Coolify deploy kills games)
  2. Tests around harvest / insolvency / win — npm test
  3. Hindi and Tamil UI strings — done (chrome only; engine logs English)
  4. CPU in online rooms
  5. Mobile board layout
  6. Trading + auctions (the biggest rules jump)
  7. Accounts / history only after rooms survive restarts
